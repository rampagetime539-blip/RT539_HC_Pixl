# Rampage Time | Pixl Maker

A personal portfolio webpage built to showcase developer links, bio, and project profiles.

## Description

This project is a clean, minimal personal landing page for Rampage, a Class 10 student and aspiring game/software developer based in Chennai. Built using HTML5 and CSS3, it features a dark-themed card layout that links to external profiles including GitHub, Hack Club Pixl, Scratch, and an original website.

## Getting Started

### Dependencies

* Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.)

* No external frameworks or runtime dependencies required.

### Installing

* Clone the repository to your local machine:

  ```
  git clone https://github.com/rampagetime539-blip/RT539_HC_Pixl.git
  
  ```

* Alternatively, download the repository source files directly as a ZIP file and extract them.

### Executing program

* To view and run the website locally:

1. Navigate to the project folder on your computer.

2. Double-click the `index.html` file to open it in your default web browser, or open it via terminal:

```
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html

```

## Help

* If the styles do not render, ensure `style.css` is saved in the exact same directory as `index.html`.

* Ensure your web browser has JavaScript/CSS enabled for proper display.
